# Database "Note PA" — RIPValGraf

Elenco delle possibili voci che compaiono casualmente nella colonna **Note PA**
della schermata di gioco. Le voci sono divise in **due macro-categorie**, che
il gioco usa anche per differenziare (in futuro) l'animazione di eliminazione
della riga.

> Questo file è la **fonte canonica** dei testi. Il gioco legge gli stessi dati
> da `notes.js` (`NOTES_DB`): se modifichi le voci qui, aggiorna anche `notes.js`
> mantenendo le due liste allineate.

Macro-categorie e chiavi usate nel codice:

| Macro-categoria             | Chiave (`notaCategoria`) |
| --------------------------- | ------------------------ |
| Prestazioni Fisioterapiche  | `fisioterapica`          |
| Prestazioni Infermieristiche| `infermieristica`        |

Totale voci: **100** (50 + 50).
