# assets

Immagini statiche del gioco.

## gameover.png
Immagine mostrata nella schermata di **Game Over** (orda di pazienti
arrabbiati con i forconi davanti all'edificio "CAD").

Per usarla: inserisci il file PNG in questa cartella con **esattamente**
questo nome (`assets/gameover.png`), poi committa e fai il deploy.
L'app la carica automaticamente al posto della pixel art SVG di fallback.
Se il file non è presente, viene mostrata la SVG di fallback (nessun errore).
